# SXRON MARKETPLAYS API

Base URL: /api

- GET /health
- POST /auth/register
- POST /auth/login
- POST /auth/logout
- GET /auth/me
- GET /categories
- GET /listings?q=&category=&city=&min=&max=&limit=
- GET/POST/DELETE /favorites
- GET /orders
- GET /chat
- POST /reviews
- POST /moderation/reports

Protected routes use the httpOnly sxron_session cookie.
