# SXRON Marketplays

Единая marketplace-платформа: объявления + полноценные магазины.

## Stack

- Next.js + React + TypeScript
- Vercel-ready web application
- PostgreSQL-ready backend layer
- Shared business core for future Android/iOS/Windows/macOS clients

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Roadmap

1. Core UI and routing
2. Authentication and profiles
3. Catalog, search and filters

6. Chat, favorites, reviews and notifications
